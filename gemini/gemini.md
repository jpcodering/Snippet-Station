Per impostare un contesto perfetto per Gemini, 
usa la struttura "RUOLO + OBIETTIVO + FORMATO + VINCOLI". 
Puoi allegare direttamente file (PDF, TXT, documenti) 
o incollare il testo usando una formattazione a blocchi chiara.

Un modello di prompt ottimale si articola in questo modo:

RUOLO (Chi sei): Esempio: "Agisci come un copywriter SEO esperto..."
CONTESTO E DATI: Fornisci le informazioni di base. Esempio: "Usa i dati aziendali allegati nel file X..." oppure "Considera che il mio target sono..."
OBIETTIVO (Cosa fare): Esempio: "Scrivi un articolo di 500 parole..."
FORMATO (Come lo vuoi): Esempio: "Usa elenchi puntati, un tono professionale e includi LaTeX per le formule [come questa: E=mc²]."
VINCOLI (Cosa evitare): Esempio: "Non usare gergo tecnico, mantieni una lunghezza massima di 1000 parole."

💡 Consiglio Pro per i file di contesto:
Gemini gestisce enormi finestre di contesto (fino a 1-2 milioni di token). 
Puoi creare documenti di "Istruzioni per il modello" o playbook di sistema 
(spesso chiamati GEMINI.md) in cui definisci le regole fisse del tuo brand, 
da caricare ogni volta che inizi una nuova chat per mantenere coerenza.
