# comandi batch

I comandi batch (.bat) sono istruzioni testuali 
eseguite in sequenza dal prompt dei comandi di Windows (cmd.exe) 
per automatizzare operazioni ripetitive

Comandi principali

ECHO: Mostra messaggi sullo schermo o attiva/disattiva la visualizzazione dei comandi (echo off).
REM: Inserisce commenti nel codice che non vengono eseguiti.
PAUSE: Ferma l'esecuzione dello script e mostra il messaggio "Premere un tasto per continuare".
CLS: Pulisce la schermata del prompt.
CD: Cambia o mostra la cartella corrente.
DIR: Elenca file e cartelle presenti in una directory.
COPY / XCOPY: Copia file o intere cartelle in un'altra posizione.
DEL / ERASE: Elimina uno o più file specificati.
MD / RD: Crea (md) o rimuove (rd) una cartella.

Struttura e controllo del flusso

IF: Esegue controlli condizionali (es. verifica se un file esiste).
GOTO: Salta a un'etichetta specifica nel file (es. :fine).
FOR: Crea cicli per ripetere operazioni su gruppi di file o numeri.
SET: Crea o modifica le variabili di ambiente.
CALL / START: Avviano programmi o script; call attende la fine del processo, mentre start apre una nuova finestra in autonomia
